# BetGenius

> BetGenius is the sportsbook-operator brand of Genius Sports, a London- and New York-listed sports
> data and technology group. It supplies licensed sportsbooks with official data and odds feeds,
> managed trading and risk (Genius Trading Services), low-latency in-play video (BetVision, Genius
> Live Player), BetBuilder same-game-parlay pricing, and player-engagement marketing (FANHub).
> There is no self-service developer portal: every credential is issued by an integration manager to
> a contracted operator, and the reference documentation lives in a public Confluence space plus a
> public Nextra docs site rather than on a developer portal.

Generated by API Evangelist from the artifacts in this repository. BetGenius publishes no llms.txt
of its own — /llms.txt returns 403 on dap-docs.betstream.betgenius.com and
developer.geniussports.com (both S3 origins) and 404 on www.geniussports.com.

## What is actually callable

- [Booking API V2](https://dataservices.betgenius.com/BookingSystem/swagger/docs/V2): Swagger 2.0, 3 operations — list bookable fixtures, book, un-book. HTTP Basic. Served from BetGenius's own host.
- [Booking API V1](https://dataservices.betgenius.com/BookingSystem/swagger/docs/V1): the same 3 operations on the pre-v2 path; still live.
- [Video Streaming API v3](https://explorer.api.geniussports.com/Video/v3/PRODPRM/swagger-latest.json): Swagger 2.0, 7 operations — list/get fixtures with streams, list regions, and exchange stream ids for authorised HLS/DASH/SRT/VOD playback URLs. OAuth2 bearer + x-api-key. RFC 7807 errors.
- [Genius Live Player](https://dap-docs.betstream.betgenius.com/video-player/web-browser-integration): a CDN script tag, not a package. Talks to the host page over a `geniussportsmessagebus` CustomEvent bus.
- [Ably push feeds](https://geniussports.atlassian.net/wiki/spaces/BID/pages/3990454301/Genius+Sports+Live+Sports+Data+Push+API+via+Ably): pub/sub match state, match events, live statistics and telemetry. Channel access is minted per fixture by a REST call; no AsyncAPI is published.

## Caveats an agent should know

- Nothing here is self-service. There is no signup, no free tier, no public sandbox credential.
- www.betgenius.com does not complete a TLS handshake; betgenius.com now redirects to geniussports.com/bet/.
- No idempotency key exists on any write operation, including the chargeable `book` call.
- No rate-limit response headers are returned anywhere; limits are prose-only.
- The Match State Platform, Statistics and Fixtures APIs run on api.geniussports.com and are
  catalogued under the parent company at all/genius-sports/, not here.
